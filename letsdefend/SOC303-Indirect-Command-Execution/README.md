# SOC303 – Indirect Command Execution via Forfiles and PowerShell

A phishing-driven attack that abused **forfiles.exe** to indirectly execute PowerShell, establish persistence using **Task Scheduler**, deploy an **HTA payload**, and perform host reconnaissance before exfiltrating collected system information.
