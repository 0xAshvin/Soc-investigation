# SOC-Investigation

Hi, I'm **Ashvin Aacharya** 👋

Welcome to my cybersecurity investigation repository.

This repository contains write-ups, notes, and lessons learned from the hands-on labs and SOC investigations I have completed on **Let's Defend**. My goal is not only to solve alerts but also to understand the attacker's mindset, investigate incidents from a SOC analyst's perspective, and document what I learn along the way.

Here you'll find:

* SOC Alert Investigations
* Incident Response Write-ups
* Malware & Threat Analysis Notes
* MITRE ATT&CK Mappings
* Detection Logic & Lessons Learned
* Personal Investigation Methodology

Every write-up is based on my own understanding of the alert, the investigation process, and the key takeaways I gained from the lab.

As I continue learning and growing in cybersecurity, I will keep updating this repository with new investigations and references.

Stay tuned for more write-ups and thank you for stopping by.
